# 使用 Chengmeng

## 下载和首次启动

从 [GitHub Releases](https://github.com/zararogers338-hash/chengmeng/releases/latest) 下载 Windows x64 EXE。首次启动自动解出运行时、插件、向量模型和 Python 环境，初始化完成后打开桌面窗口，并创建快捷方式。

第一次使用需要自己的模型账号或 API Key。发行包没有预登录账号，也不附送模型服务额度。

## 记忆怎么用

在 Chengmeng 会话中正常聊天即可。默认自动保存聊天档案和整理记忆，不需要逐条确认。可以直接询问“上周我们聊了什么”“之前提过的项目是什么”，模型会按记忆协议调用工具检索。

`memory_status` 查询实际状态；`recall_memory` 查询整理记忆；`recall_history` 查询完整聊天档案；`propose_memory` 保存一条整理记忆。查询没有结果时，应区分没有保存、时间范围不匹配和检索环境不可用，不把空结果当成从未发生。

记忆管理界面提供开关、查看和删除等操作。历史记录、长期记忆、派生索引是不同数据，删除时以界面展示的实际范围为准。

## 文件与网络

可以上传文件或让助手读取工作区中的文件。可用的读写、命令和网络操作取决于宿主工具注册和访问模式。处理文件前选择合适的工作区；工具结果返回后再判断任务是否完成。

联网搜索与在线模型调用需要网络。本地 CPU 向量化和已有资料的关键词查询不需要下载新的模型权重。

## 数据位置

| 内容 | 默认目录 |
| --- | --- |
| 应用版本 | `%LOCALAPPDATA%\Chengmeng\packages` |
| 账号配置、会话和附件等使用者数据 | `%LOCALAPPDATA%\Chengmeng\data` |
| 自动记忆、聊天档案与检索索引 | `%LOCALAPPDATA%\Chengmeng\data\chengmeng\memory` |
| 启动日志 | `%LOCALAPPDATA%\Chengmeng\launcher.log` |

记忆使用明文存储。向量计算在本机运行，聊天模型则使用当前配置的服务；召回内容可能进入模型上下文。

## 更新与已有数据

关闭旧实例，再运行新版 Chengmeng EXE。应用文件使用独立版本目录，现有数据不随程序替换而清空。

需要接续已有的 Harness 数据目录时，可显式指定：

```powershell
.\Chengmeng-0.5.0-Windows-x64.exe --data-home 'D:\ChengmengData'
```

路径应是原有 `DSH_HOME` 根目录，而不是某个工作区或单独的记忆子目录。成功准备后，启动器会在本机记住选择。先关闭使用同一数据目录的其他实例。

共享软件时分享 Release 文件即可；账号、会话和附件属于安装后生成的使用者数据，不应混入软件发布包。

## 常见情况

### 第一次启动比较慢

初次需要解压大型依赖并离线安装 CPU Python 环境，可能耗时数分钟。后续启动复用已安装环境，不重复下载模型。

### 没有 GPU

内置 Qwen3-Embedding-0.6B 使用 CPU。默认 4 个计算线程，向量维度为 1024，空闲后释放工作进程。默认在启动向量模型前检查至少 4 GB 可用内存。

### 向量检索暂时不可用

检索模块可退回关键词。用 `memory_status` 检查实际后端和降级原因；记忆仍保存在磁盘。若整个初始化未完成，先查看启动日志中的具体失败，再重新运行安装包。

### 打开后提示登录

这是新安装的正常状态。请使用自己的账号，或通过账号界面添加自己的 API Key。

### 想自定义提示词和外观

修改 `plugins/agent-core/persona/`、相关插件源码后运行 `npm run build`，再按构建指南生成新的 EXE。已开始的会话可能保留旧预设，用新会话验证提示词更新。

## 启动参数

| 参数 | 用途 |
| --- | --- |
| `--data-home <绝对路径>` | 选择数据根目录 |
| `--install-root <绝对路径>` | 选择解包和安装根目录 |
| `--prepare-only` | 解包和准备组件，不打开主窗口 |
| `--no-shortcuts` | 不创建快捷方式 |
| `--isolated` | 完整安装包验收时不读写默认启动偏好 |
| `--quiet` | 隐藏准备窗口，错误写入启动日志 |
